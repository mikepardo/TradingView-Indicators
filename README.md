# TradingView-Indicators

Pine Script v6 indicators.

## Indicators

- **MP_TD_Seq_V1.pine** — TD Sequential (Setup + Countdown).
- **MP_Consolidation_Breakout_V6.pine** — Consolidation & Breakout Detector v6: coil detection with adaptive or fixed-percent engines, close-confirmed breakouts, trade plans (entry / stop / T1 / T2), retest entries, failed-break and stop exits, and frozen S/R zones that flip roles when broken.
